## Project Description

This project is a personal website created using HTML only.
The website contains information about me, my education,
hobbies, skills and contact information.

## Question 1: Website Creation

I created a personal website using HTML. It contains sections
for About Me, Education, Hobbies, Skills and Contact.

The website uses more than 25 HTML elements and more than
15 HTML attributes. It also uses semantic HTML elements
such as header, nav, main, section, article and footer.

## Question 2: HTML Elements

### 1. Five challenging elements

The five elements I found most challenging were form, nav,
figure, dl and textarea because they have different purposes
and require other elements or attributes to work correctly.

### 2. Semantic elements

I used header, nav, main, section, article and footer to
organize the content of my website.

### 3. Most useful element

The section element was the most useful because it helped
me divide the website into clear sections.

## Question 3: HTML Attributes

### 1. Three essential attributes

The three essential attributes were href, src and id.

### 2. Class and id

I used class to group elements with similar characteristics.
I used id to give individual sections unique names and to
allow navigation links to move to specific sections.

## Question 4: Development Process

### 1. Planning

I planned my website by deciding on the different sections
before starting to code. These included About Me, Education,
Hobbies, Skills and Contact.

### 2. Testing and debugging

I tested my website using the browser and Phoenix Code's
live preview. When I found errors, I checked my HTML tags
and attributes and corrected them.

### 3. Challenges

One challenge was arranging the navigation links horizontally.
I solved this by changing the navigation structure. I also
checked my image file name and location when the image did
not appear.
